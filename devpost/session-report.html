What was made

A one-page web app: paste what an AI agent claimed and the evidence, press CHECK IT, get one honest verdict — VERIFIED (green), CLAIMED-ONLY (amber, the default), or DISPUTED (red) — with the evidence checklist, a STATED → SOLD meter, and a ledger stamp (time + SHA-256). Deterministic, offline, zero dependencies, no accounts, no storage. Two one-click examples; three static sample report cards.

Decisions worth keeping

  • One verdict, never a score — no percentages, no "100% done."
  • Same boxes, same verdict, every time — learning/evolution explicitly barred from the proof.
  • Verify from specs, not memory — the engine reads only the two boxes, never outside knowledge.
  • Kernel first: the check logic was specified before any code, and the build answered to fixed examples ("fix the logic, not the examples").
